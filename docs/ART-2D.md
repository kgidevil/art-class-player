# ART 2D — lessons and class history (v0.6.0)
- Default class profiles: Cheongun and Danwol; user can add named profiles. Local group selection, history and named reusable presets persist without changing image IndexedDB schema.
- Existing quick session remains available. Optional program expands configurable drawing steps (seconds/count) and break steps; preview concrete photo order, reorder entries, insufficient-photo warning rather than silent duplication. Uses current saved photo source/category. Each program uses distinct photo keys.
- Variable-duration clock supports previous/next, pause, extend and restart; saved session includes durations, synthetic break entries and group/session metadata. Old positive-ID checkpoints remain compatible. Photo ID allocation uses timestamp floor to reduce reuse. Recovery always paused.
- Per-class unused-first ranks never-used images first, followed by least recently shown. In simple mode random option shuffles ties; reuse is allowed after unused pool is exhausted. Explicit no-reuse across lessons is not enforced; within program duplicates prohibited.
- History records shown unique images, configured per-image duration, overall elapsed wall time (including pause, break and closed time), completion/early end and editable teacher note (saved on blur). Actual accumulated active seconds per image, editable future lesson memo, class deletion/rename, and backup/export are not in this patch. History capped at 500 records. No cloud upload.
- Automated tests added for variable timers, plan validation, class ranking and browser preset/break/recovery/history. Actual Windows and iPad validation pending. Pages still needs owner configuration.
