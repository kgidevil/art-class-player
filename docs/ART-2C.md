## Weekly workflow
- ChatGPT curation target 45/week: 20 croquis, 10 landscape, 5 portrait, 5 still life, 5 other; quality and rights take priority over quota. Prefer varied clothed adults, visible full bodies, neutral backgrounds; partial poses must be explicitly labeled. Inspect visual preview and source license, credit, dimensions. Do not infer model releases. No copyrighted material without explicit redistribution permission. Keep originals unmodified; credits preserved.
- Append only approved items to content/approved.json. Each item must have existing schema fields plus review {date,visual:true,note,width,height}. Use stable IDs; source and original upload URL must match the actual file, not guessed.
- GitHub Actions content.yml runs on queue push, Tuesday 09:30 KST, or manual dispatch. Verifies metadata via Commons API, live license URL, original URL, dimensions, file size <=25MiB, decode via sharp, SHA1 and SHA256, exact duplicate source/ID. Minimum short side 800 and long side 1200. Existing records without hashes have Commons SHA1 looked up where available. Similar-looking but nonidentical images require visual review, no perceptual-hash guarantee.
- Successful approved items append to catalog; version increments once, current data untouched. Errors skip item or fail closed; no accepted items => no publication. Git push is non-force and fails if branch advanced. Queue is retained for idempotence. No secrets or paid API. Source may rate-limit or deny runner requests. GitHub Actions commits using GITHUB_TOKEN do not automatically trigger normal push workflows; publisher explicitly validates content before push. App reads raw GitHub catalog independently of Pages. Public catalog is metadata/links, not private user photos.
- Scheduled curation is a separate ChatGPT task; scheduling success is not proof of future connector access, visual inspection, or publication. Each run must report actual commit/publication verification, and stop on auth/verification failure. No unreviewed automatic discovery publication.
