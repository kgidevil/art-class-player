# ART CLASS PLAYER — SAI COMPANY

아이패드 중심 미술교육 전용 이미지 플레이어. ART 2B (v0.5) 제공 이미지 라이브러리 개발 및 검증.

## 사용 방법
사진 여러 장을 가져오고 30초~20분 프리셋 또는 직접 입력을 선택하여 수업을 시작합니다. 순차/무작위, 자동 전환, 시간 연장, 일시정지, 이전/다음, 원본 비율 유지, 발표 화면을 지원합니다. 사진은 서버에 전송하지 않고 IndexedDB에 원본을 보관합니다. 다음 실행 시 다시 불러오며 수업 중단 시 남은 시간과 순서를 일시정지 상태로 복구할 수 있습니다.

## Windows 개발 및 테스트
Node.js 22:
```powershell
npm install
npm run dev
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```
GitHub Actions에서 Linux 빌드 및 타이머 단위 테스트와 Windows Chromium 브라우저 테스트를 실행합니다.

## 범위
- ART 1A: 기본 플레이어 및 SAI 브랜드 UI.
- ART 1B: 로컬 이미지 저장, PWA, 오프라인 실행, 수업 복구. 최초 온라인 설치 후 오프라인 준비 상태를 확인하세요.
- 발표는 미러링용 화면으로 독립 외부 디스플레이가 아닙니다.
- 탭이 숨겨지면 일시정지합니다. 실제 iPad 화면 잠금/외부 출력은 최종 실기기 검증 대상입니다.
- 사용자 사진은 공개 저장소에 등록하지 않습니다.
- 로고 경로: public/sai-logo.jpg (첨부 로고의 240px 축소 JPEG, 원본 해상도 파일은 미등록).
- GitHub Pages: https://kgidevil.github.io/art-class-player/ (실제 배포 성공 확인 필요). Settings → Pages → Source → GitHub Actions 설정이 필요할 수 있습니다.
- 로컬 개발 주소와 배포 주소의 데이터는 서로 별도입니다. 브라우저 데이터 삭제 시 사진이 사라질 수 있습니다. 백업 기능은 추후 개발.
- ART 1A 사용자 테스트 10/10 통과: [검증 기록](docs/ART-1A.md).
- ART 1B: [구현 및 검증 범위](docs/ART-1B.md). 오프라인 로컬 테스트는 npm run build 후 npm run preview로 확인하세요.

## SAI 제공 자료
자료 둘러보기 → 주제/난이도 선택 → 기기에 저장 → 재생 자료 범위에서 제공 자료 선택. 최초 목록 확인 및 사진 다운로드는 인터넷 연결 필요. 저장한 이미지는 오프라인에서 재생할 수 있습니다. 자료는 Wikimedia Commons의 개별 파일별 라이선스를 확인한 파일이며 작가·출처·라이선스를 표시합니다. 외부 서버 다운로드가 실패하면 재시도 안내가 표시됩니다. 정기 콘텐츠 자동 게시 작업은 아직 설정하지 않았습니다.

ART 2B: 신규 자료 자동 다운로드는 선택 설정이며, 앱 시작/재연결/15분 간격으로 최신 GitHub 자료 목록을 조회합니다. 제공 사진 즐겨찾기 및 용량 표시 지원. [개발 문서](docs/ART-2B.md). 정기 자료 발행은 ART 2C에서 구성합니다.

## ART 2C: SAI 정기 콘텐츠 공급
검토된 신규 자료는 `content/approved.json`에 추가하고 GitHub Actions의 SAI reviewed content publication 작업에서 파일별 원본 URL, 라이선스, 해상도, 크기, 다운로드 및 중복 검사를 거쳐 `public/content/catalog.json`에 게시합니다. 앱은 기존 ART 2B 버전에서 최신 목록을 받을 수 있습니다. [정기 큐레이션 운영 규칙](docs/ART-2C.md).

## ART 2D: 수업 프로그램 및 강의실별 기록
청운면·단월면 또는 새 강의실을 선택하고 수업 프로그램 만들기에서 그림 단계(초/장수), 휴식, 순서를 설정합니다. 재생 순서 미리보기 후 시작하거나 기존 단일 시간 수업을 사용합니다. 수업 기록은 해당 강의실별로 저장되며 메모는 입력 후 다른 곳을 클릭하면 저장됩니다. 사진별 기록 시간은 설정 시간, 전체 경과는 휴식/정지 포함 실제 경과입니다. [상세 범위](docs/ART-2D.md).

ART 2D-1: 프로그램 시간 입력은 분 단위(0.5분 = 30초)이며 빠른 시간 선택, 단계별 소요 시간 및 전체 요약을 제공합니다. 사진 다운로드 중에도 강의실·프로그램을 저장할 수 있으며 수업 시작 제한 사유가 표시됩니다.

## ART 3A: 미술 보조 도구
수업 중 상단 **미술 도구** 버튼에서 흑백, 단계별 명암, 윤곽선, 격자, 반전, 밝기·대비·채도, 확대와 원본 비교를 사용할 수 있습니다. 화면에만 적용되고 저장한 원본은 변경되지 않습니다. 타이머는 자동으로 정지하지 않으므로 필요하면 일시정지하세요. [ART 3A 상세 범위](docs/ART-3A.md).

## ART 3B: 강사 모드
수업 중 **드로잉**에서 펜·지우개·이동을 선택합니다. 설명선은 수업 중 사진별로 유지되지만 앱 종료/새로고침 시 저장되지 않습니다. 강사 모드는 다음 단계와 전체 진행률을 표시하며 발표 화면에서는 다음 사진을 숨깁니다. 애플펜슬은 브라우저 펜 입력 대응이며 실기기 검증 전입니다. [상세 범위](docs/ART-3B.md).
